# فيلا بأسلوب بوهيمي راقٍ — توزيع المساحات والخامات

المرجع: `ground-floor-plan.jpg` (مسقط الدور الأرضي، أرض تقريباً 19.5 × 26.4 م، الواجهة الرئيسية على شارع 30 م).

## روح التصميم

بوهيمي **محترم وهادئ**: دفء الخامات الطبيعية والحِرَف اليدوية، بدون فوضى أو ألوان صارخة، ومتوافق مع الخصوصية والمجلس الخليجي.

| العنصر | الاختيار |
|---|---|
| الألوان | رملي، عاجي، تيراكوتا، زيتوني، كونياك، ولمسات نيلية قليلة |
| الأرضيات | ترافرتين مطفي (Honed) للمداخل والصالات، باركيه بلوط للغرف، زليج يدوي للحمامات |
| الجدران | لياسة جيرية / تدلاكت، مع أقواس ومحاريب (Niches) |
| الخشب | بلوط طبيعي وجوز للأبواب والخزائن والطاولات |
| الألياف | راتان وقصب (Cane) في الخزائن والكراسي، سجاد صوف معقود يدوياً وجوت |
| الأقمشة | كتان وبوكليه للكنب، ستائر كتان شفافة، وسائد كليم |
| المعادن | نحاس مصقول مطفي (Brushed Brass) للإكسسوارات والإنارة |
| الإنارة | معلقات منسوجة (راتان)، فوانيس نحاسية، إضاءة غير مباشرة دافئة 2700K |
| النباتات | زيتون، نخيل، نباتات داخلية كبيرة في أصص فخارية |

## توزيع المساحات

### خارجي
| المساحة | المقترح |
|---|---|
| **الواجهة والفناء الأمامي** | حجر جيري ولياسة جيرية، باب خشبي مقوّس بمقابض نحاسية، حوض زراعي دائري بشجرة زيتون، نخيل، إضاءة جدارية دافئة |
| **حوش المسبح والجلسة الخارجية** | مسبح بزليج أخضر، ديك خشبي، نخيل على الحافة، جلسة أرضية منخفضة تحت برغولا خشبية بتظليل راتان، فوانيس |
| **المواقف والممر الجانبي (السكة 6 م)** | أرضية ترافرتين، بوابة خشب شرائحي، جدار أخضر، ممر حجري مع حصى وإنارة أرضية منخفضة |

### داخلي
| المساحة | المقترح |
|---|---|
| **المدخل الرئيسي GF-12** | محراب مقوّس مع كونسول منحوت، مرآة منسوجة دائرية، سجادة ممر، خزانة أحذية قصب وبلوط |
| **المجلس GF-13 (5.1 × 6.1 م)** | جلسة منخفضة على شكل U بقماش بوكليه عاجي، وسائد كليم، سجادة كبيرة، طاولات جوز، ركن قهوة (دلة)، فوانيس نحاسية |
| **الصالة والطعام GF-05 (دبل هايت)** | كنبة كتان عميقة، كراسي راتان، معلّق منسوج كبير في الفراغ المزدوج، طاولة بلوط لثمانية بكراسي قصب، بوفيه بخلفية زليج |
| **المطبخ GF-04** | جزيرة ترافرتين على قاعدة بلوط، خزائن سفلية زيتونية بحشوات قصب، أرفف مفتوحة، زليج يدوي، شفاط مكسو بلياسة |
| **متعددة الاستخدامات GF-06 (4.5 × 4.2 م)** | مكتبة وجلسة عائلية: سرير نهاري (Daybed)، رفوف بلوط من الأرض للسقف، مكتب، قابلة للتحول لغرفة لعب ودراسة |
| **غرفة نوم الضيوف GF-11 + حمام + خزانة** | سرير كتان بظهر راتان مقوّس، مفارش رملية وتيراكوتا، محاريب جانبية، سجادة جوت |
| **الدرج والمصعد** | درجات ترافرتين، درابزين ملبّس لياسة، معلّق كبير في بيت الدرج، باب المصعد مكسو بلوط |
| **الحمامات ودورات المياه** | تدلاكت، مغسلة حجرية على وحدة بلوط، مرآة نحاسية دائرية، زليج تيراكوتا للشاور |
| **غرفة العبايات GF-15** | خزائن بلوط وقصب، مقعد منجّد، مرآة مقوّسة بطول كامل، علاقات نحاسية |
| **الخدمات (المخزن، غرفة السائق)** | تشطيب عملي بنفس الألوان، بلا معالجة ديكورية |

## توليد الصور

السكربت `generate_renders.py` يرسل المسقط كمرجع مع وصف لكل لقطة إلى Gemini، ويحفظ الصور في `renders/`.
**24 صورة** موزعة على 12 مساحة (2–3 لقطات لكل مساحة). كل صورة طلب مدفوع.

```bash
cd design/bohemian-villa
export GEMINI_API_KEY="مفتاحك-الجديد"        # لا تضعه في أي ملف داخل المستودع
python3 generate_renders.py --list            # عرض المساحات (مجاني)
python3 generate_renders.py --dry-run         # عرض الأوصاف وعدد الصور (مجاني)
python3 generate_renders.py majlis living     # مساحات محددة فقط
python3 generate_renders.py                   # كل الصور
```

- النموذج الافتراضي `gemini-3.1-flash-image`. لجودة أعلى: `--model gemini-3-pro-image`.
- نسبة العرض الافتراضية 16:9، وتتغير بـ `--aspect 4:3`.
- يحتاج Python 3 فقط، بدون مكتبات إضافية.

> الصور تقريبية وتوضيحية: النموذج لا يلتزم بالمقاسات حرفياً، فراجِع كل لقطة مقابل المسقط قبل اعتمادها.
